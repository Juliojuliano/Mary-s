# Mary's Brinq

[![Vercel](https://img.shields.io/badge/deploy-vercel-000000?style=flat&logo=vercel&logoColor=white)](https://marys-brinq.vercel.app)

Landing page para Mary’s Brinq — locação de brinquedos, mesas e cadeiras no ABC.

## Visão geral

- Tecnologia: React + TypeScript + Vite
- Build de produção: `npm run build`
- Diretório de saída: `dist/`
- Deploy atual: https://marys-brinq.vercel.app

## Como rodar localmente

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

3. Abra o navegador em `http://127.0.0.1:5174`.

## Build de produção

```bash
npm run build
```

A pasta `dist/` será gerada com os arquivos prontos para deploy.

## Deploy no Vercel

O projeto está vinculado ao Vercel e pronto para deploy automático no repositório.

Para redeployar manualmente:

```bash
npx vercel --prod --yes
```

## Estrutura principal

- `src/App.tsx` — componente principal da landing page
- `src/styles.css` — estilos da página
- `public/foto05.jpeg` — favicon e logo
- `src/imagens/` — imagens usadas na galeria
